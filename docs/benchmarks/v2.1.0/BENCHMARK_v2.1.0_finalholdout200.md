## Interpretation

The candidate pool reaches **99.50% parent-level coverage**, so document discovery is not the primary bottleneck.

V3 materially improves early ranking, reaching **97.00% parent-level AnyHit@5**.

The primary remaining bottleneck is downstream evidence/citation alignment. Trusted parent citation precision is **72.73%**, while citation recall and coverage remain substantially lower.

Deterministic citation repair reduces citation mismatches from **93 to 6 (93.55% reduction)**.

## Evaluation limitations

1. Evidence and citation metrics use **answer-aware Silver Oracle** labels, not official human-annotated gold citation labels.

2. Silver Oracle evidence is used only for evaluation and is **never used during inference**.

3. Grounding metrics are generated by the frozen deterministic legal-aware validator. Unsupported Claim Rate is not a definitive hallucination rate.

4. Shipping-gate PASS measures compliance with conservative runtime validation requirements and is not equivalent to answer accuracy.

5. Historical Dev600 and competition-era generation metrics are not the primary v2.1.0 benchmark.
